Before you start

常见问题。

还有疑问？先看看这里。启动器里也保留了清晰的账户、Java 与下载状态提示。

01启动器是免费的吗？

NeoCatCraftLauncher 本身免费。Minecraft 游戏与 Microsoft 账户需要遵守各自的授权规则；启动器不提供游戏或账户售卖服务。

02使用正版账户登录安全吗？

登录采用 Microsoft 官方设备代码流程，你会在浏览器中完成确认。启动器只在本地保存必要的账户令牌，用于后续验证和启动游戏。

03可以自动下载模组加载器吗？

可以。按所选 Minecraft 与加载器版本，会自动从 Forge、NeoForge、Fabric 或 Quilt 的官方文件源下载安装器 JAR。你也可以改用提前下载的本地官方 JAR。

04一定要单独安装 Java 吗？

不一定。启动器可以根据 Minecraft 版本检查所需的 Java 主版本，并按需下载 Zulu 运行时；已有兼容 Java 时也可以手动指定。

05支持哪些模组下载平台？

目前整合 Modrinth 与 CurseForge 的搜索与版本信息，可以按 Minecraft 版本和模组加载器筛选，并在下载前提示前置依赖。
